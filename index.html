🔔 Notificaciones Push
—
Suscriptores activos
Tipo de notificación
⚙️ Configuración requerida

Para que las notificaciones funcionen necesitás completar 3 pasos:

1. En Firebase Console → Cloud Messaging → Certificados push web → Generar par de claves → copiá la clave pública y pegála como VAPID_KEY en el HTML y en el sw.js

2. Subí firebase-messaging-sw.js a la raíz de tu hosting (mismo nivel que el HTML) con los mismos datos de Firebase

3. Para enviar pushes cuando cerrás el admin, activá Firebase Cloud Functions con el trigger onDocumentWritten('lrr/push_pendiente')
